# \# \[PRD] 스마트 알고리즘 프로젝트 로드맵 \& 액션 플래너 (No-API 안전 버전)

# 

# \## 1. 제품 개요

# \- \*\*정의\*\*: 외부 AI API 의존성(키 만료, 토큰 제한)을 완전히 제거하고, 브라우저 단독 기동이 가능한 내장형 매트릭스 알고리즘 엔진 기반의 프로젝트 로드맵 및 5단계 액션 플래너.

# \- \*\*목적\*\*: API 가동 중단 리스크를 원천 차단하여 Vercel 배포 안정성을 100% 확보하고, 기획/개발/QA 에이전트 협업 체계를 증명함.

# 

# \## 2. 핵심 기능 요구사항

# 1\. \*\*기존 UI/UX 유지\*\*: 세련된 대시보드 톤앤매너, 왼쪽 히스토리 사이드바 및 메인 결과 영역 레이아웃 유지.

# 2\. \*\*로컬 매트릭스 연산 시스템\*\*: `skills/matrixEngine.js`를 통해 유저가 입력한 프로젝트 명칭과 선택한 카테고리(IT/개발, 마케팅, 자산관리, 루틴/헬스)를 분석하여 커스텀 마일스톤 및 5단계 To-Do 리스트를 실시간 동적 생성.

# 3\. \*\*상태 보존\*\*: 생성된 로드맵과 5단계 실행 계획의 체크박스 상태는 LocalStorage에 저장되어 브라우저를 껐다 켜도 완벽히 유지됨.
